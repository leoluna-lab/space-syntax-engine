Protocolo de codificação de exemplares

Como transformar a planta de uma casa (levantamento, desenho de arquivo, croqui) em um exemplar: um arquivo com os espaços convexos, as interfaces entre eles, as faces voltadas para fora e os dados de origem. Todos os exemplares precisam ser codificados do mesmo jeito para que possam ser comparados entre si e com as plantas geradas pelo programa.

Antes de começar: abra o aplicativo, vá em Modelo → Modo de trabalho → Pesquisa e crie um cenário para a casa em Modelo → Cenários → Novo em branco (cada casa = um cenário). Os dados ficam no navegador do aparelho; exporte o exemplar ao terminar (passo 10).

1. Passo a passo

  1. Planta de fundo. Carregue a imagem da planta em Modelo → Planta de fundo e ajuste opacidade, rotação e escala até ficar confortável para traçar por cima.
  2. Escala. Em Modelo → Polígonos convexos → Escala → Calibrar, toque nos dois extremos de uma medida conhecida (uma parede cotada) e informe a distância real em metros. Sem escala, as tolerâncias ficam provisórias. Se a casa tiver modulação, informe o módulo em metros no formulário do exemplar.
  3. Espaços convexos. No modo Convexo (pentágono), toque os vértices de cada espaço e feche tocando no primeiro ponto. Um espaço é convexo quando nenhuma reta entre dois pontos dele sai dele (Hillier & Hanson 1984); um cômodo em L vira dois espaços. Use o ímã: o ponto gruda nos cantos (círculo azul) e nas paredes (losango) dos vizinhos. Para dois cômodos que dividem a parede, comece o segundo sobre a parede do primeiro e toque "Usar a parede inteira".
  4. Função. Toque em cada espaço e preencha Função (estar, cozinha, dormitório, varanda, circulação…). Use sempre os mesmos nomes em todos os exemplares.
  5. Vizinhanças. Em Polígonos convexos → Detectar vizinhanças…, confira a lista. Certas e prováveis vêm marcadas; duvidosas só entram se você marcar. Toque num par para vê-lo no mapa. Se houver frestas, use Fechar frestas e depois Criar ligações. Toda vizinhança entra como opaco; a categoria certa vem no passo 8. Todo par de espaços que se toca deve ter ligação, inclusive os separados por parede cega.
  6. Exterior. Em Exterior e orientação, toque Criar exterior (um único nó representa todo o lado de fora; ele vira a raiz do grafo).
  7. Norte e faces. Informe para onde aponta o norte (0° = para cima da tela, sentido horário). Toque Sugerir faces…: o aplicativo propõe, para cada espaço, as faces (N, S, L, O) em que ele encosta no exterior. Desmarque o que estiver errado (por exemplo, um pátio interno ou um espaço que faltou desenhar) e grave. Um cômodo de canto tem uma ligação para cada face.
  8. Categoria de cada ligação. Toque em cada ligação (no mapa ou na lista) e escolha a categoria pela tabela da seção 2. No computador, as teclas 1–4 também mudam a categoria da ligação selecionada.
  9. Metadados. Preencha em Exemplar: identificador, conjunto, fonte, local, data, quem codificou e notas (registre ali as decisões difíceis).
  10. Conferir e exportar. A lista Conferência aponta o que falta; itens em vermelho comprometem o uso do exemplar. Toque Exportar exemplar (JSON) — o arquivo leva o nome do identificador — e Manifesto (CSV). Envie os dois arquivos para a coordenação da pesquisa.

2. Categorias de interface

A categoria é do par de espaços, não de cada abertura: cada par tem uma única ligação (com o exterior, uma por face).

CategoriaTraço no mapaQuando usarExemplos
opaco pontilhadoOs espaços se tocam, mas não há passagem nem vista.parede cega, divisória fechada
vista tracejadoHá vista (ou ar, luz) de um para o outro, mas não se passa.janela, cobogó, treliça, bandeira vazada, peitoril
acesso contínuoPassa-se por uma porta (que pode ser fechada).porta, porta-janela, portão
aberto linha duplaNão há divisão: os dois espaços se abrem inteiramente um para o outro. Continuam sendo dois espaços convexos.vão livre, arco sem porta, varanda aberta para o terreiro
Regra provisória — a confirmar pela coordenação: quando um mesmo par tem aberturas de tipos diferentes (por exemplo, porta e janela na mesma parede), registre a mais permeável: aberto > acesso > vista > opaco. Anote o caso nas notas do exemplar.

Casos frequentes

  • Porta para fora: ligação acesso entre o espaço e o exterior, na face em que a porta está.
  • Janela para fora: ligação vista com o exterior, na face da janela. Parede externa sem abertura: opaco.
  • Varanda: é um espaço convexo; sua relação com o exterior costuma ser aberto em cada face livre.
  • Cômodo em L ou em T: divida em espaços convexos ligados por aberto.
  • Encostar só pela quina: não é vizinhança; não crie ligação.

3. Conjuntos

definiçãoOs exemplares reais que definem o padrão (genótipo) estudado.
validaçãoExemplares novos, codificados depois, para testar se o padrão prevê casas que não foram usadas para defini-lo.
sintéticoPlantas geradas pelo programa (não use para casas reais).

4. Boas práticas

  • Codifique o que a fonte mostra, não o que você supõe; registre dúvidas nas notas.
  • Use sempre o mesmo vocabulário de funções.
  • Exporte o exemplar ao terminar cada sessão: os dados do navegador podem ser apagados pelo sistema (especialmente no iPhone).
  • O arquivo exportado segue o schema público schema/v3.json, o mesmo usado pelo validador da pesquisa.

English summary

Switch to Research mode and create one scenario per house. Load the plan as background, calibrate the scale, draw the convex spaces (the magnet snaps to neighbours' corners and walls; use "Use the whole wall" for shared walls) and set each space's function. Run Detect neighbours…, review, close gaps and create the links (all start as opaque). Create the exterior, set north and run Suggest faces…. Then classify every link: opaque (blank wall), view (window, cobogó), access (door), open (no partition; still two convex spaces). Fill in the metadata, check the list, and export the exemplar (JSON, schema 3) and the manifest (CSV). Provisional rule, to be confirmed: if a pair has openings of different types, record the most permeable one.
